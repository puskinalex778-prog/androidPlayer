# Aura Player 📼

Музыкальный плеер для Android в стиле 2026: свои песни из памяти телефона и с карты памяти, эффекты голоса, 10-полосный эквалайзер, онлайн-радио 5 стран с выбором битрейта и ретро-кассета с обложкой альбома.

## Возможности

- **Медиатека**
  - автоматически находит музыку во **внутренней памяти и на карте памяти** (все тома хранилища);
  - кнопки **«Добавить файлы»** и **«Добавить папку»** — можно выбрать любую папку на SD-карте;
  - «Открыть с помощью → Aura Player» из любого файлового менеджера;
  - форматы: MP3, FLAC, M4A/AAC, OGG/Opus, WAV, AMR, MKA и др.;
  - вкладки Треки / Альбомы / Исполнители / Папки, фильтры «Карта памяти» и «Добавленные», поиск, сортировка, очередь, «Играть следующим»;
  - плеер запоминает последний трек и позицию.
- **Ретро-кассета** — на наклейке кассеты рисуется **обложка альбома, встроенная в файл** (ID3/FLAC/MP4-обложка). Катушки крутятся, плёнка перематывается с одной катушки на другую по мере проигрывания. Можно переключиться на большую обложку (кнопка 📼/🖼️).
- **Эффекты голоса** — Детский, Гелий, Бурундук, Злой, Демон, Великан, Робот, Пещера, Концертный зал, Телефон, Под водой, Винил, Караоке (убирает вокал) + ручная настройка тона (±12 полутонов) и скорости.
- **Эквалайзер** — собственный 10-полосный DSP-эквалайзер (работает на любом телефоне), 14 пресетов, усиление баса, объёмный звук, предусиление, мягкий лимитер.
- **Онлайн-радио** — ~80 популярных станций **России, США, Германии, Франции и Южной Кореи** (KBS, MBC, SBS, CBS…), выбор битрейта у каждой станции, качество по умолчанию «Эконом/Стандарт/Максимум», автопереключение на другой битрейт при сбое, название песни в эфире, избранное, свои станции по ссылке, поиск по мировому каталогу radio-browser.info.
- **Фоновая работа** — играет при свёрнутом приложении и выключенном экране; уведомление с кнопками, управление с экрана блокировки и наушников; пауза при звонке и отключении наушников.
- **Темы** — Аврора, Неон, Закат, Океан, Лес, Сакура, Ретро-кассета, Киберпанк, Графит, Material You; тёмный/светлый/системный режим, чёрный AMOLED, цвет интерфейса из обложки песни.
- **Визуализатор спектра** без разрешения на микрофон, таймер сна с плавным затуханием.

## Сборка APK через GitHub

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него **содержимое папки `Player`** — так, чтобы `settings.gradle.kts`, `app/` и `.github/` лежали **в корне** репозитория.
   - Через сайт: *Add file → Upload files* → перетащите все файлы и папки. Папку `.github` проводник может скрывать — включите показ скрытых элементов.
   - Или через git:
     ```bash
     cd Player
     git init && git add . && git commit -m "Aura Player"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/AuraPlayer.git
     git push -u origin main
     ```
3. Откройте вкладку **Actions** — сборка «Build APK» запустится сама (или нажмите *Run workflow*).
4. Через ~5–8 минут откройте завершённый запуск → внизу **Artifacts** → скачайте `AuraPlayer-apk` (zip с APK).
5. Установите APK на телефон (разрешите установку из неизвестных источников).

> Файл `local.properties` (путь к Android SDK на компьютере) загружать не нужно — он в `.gitignore`.

## Если что-то не работает

- **Песни с карты памяти не видны** → «Медиатека» → «Добавить папку» → в меню ☰ выберите SD-карту → папку → «Использовать эту папку».
- **Станция не играет** — выберите другой битрейт или найдите станцию в онлайн-каталоге. Корейские KBS/MBC/SBS могут быть недоступны за пределами Кореи.
- **Музыка останавливается в фоне** (Xiaomi/Huawei/Samsung) — в настройках приложения отключите «Оптимизацию батареи» / включите «Автозапуск».
- Каждая сборка на GitHub подписывается новым debug-ключом — перед установкой новой версии удалите старую.
