# PoliSANPlayer V1.6 📼

Музыкальный плеер для Android в современном плоском и настраиваемом стиле: музыка из памяти телефона и с карты памяти (только пути, без копирования), 32-битный DSP-процессор, эффекты голоса (включая **8D Audio**, **Slowed+Reverb** и **Nightcore**), 10-полосный эквалайзер, онлайн-радио 5 стран, ретро-кассета и 9 частотных визуализаторов.

## Новое в V1.6

- **Имя сборки**: `PoliSANPlayer-V1.6.apk` (отображаемое имя приложения — **PoliSANPlayer**).
- **Визуализация «Party»** — динамичные прожекторы, лазерные лучи и стробоскопы в такт басу и биту.
- **Прокачанные «62 LED» и «Пиксели»** — 62 многослойные лампочки рядами (`12+13+12+13+12` в большом окне и `2×31` в полосе плеера) с объёмным свечением и улучшенный 16-битный пиксельный спектр со шлейфом искр.
- **Свайп вниз по верхней зоне / сцене плеера** — сворачивает полноэкранный плеер обратно к списку треков и плейлистам; **свайп вверх по мини-плееру** — раскрывает плеер.
- **Индикатор таймера сна справа вверху** + режим **«В конце текущего трека»**.
- **Настраиваемая нижняя панель плеера** — выбирайте 2–5 быстрых кнопок в меню, настройках или долгим нажатием на панель (Голос, EQ, Таймер, Вывод, Радио, Плейлисты, Очередь, Текст песни, Скорость, Визуал, Закладки, Режим Авто, Инфо).
- **Новые функции**:
  - **Текст песни (LRC и обычный текст)** — встроенные теги `USLT`, загрузка `.lrc` / `.txt` и редактирование вручную с автопрокруткой;
  - **Закладки внутри трека** — удобно для длинных миксов, подкастов и аудиокниг;
  - **Эффекты `8D Audio`**, **`Slowed+Reverb`**, **`Nightcore`**;
  - **Режим Авто** — гигантские кнопки управления и не гаснущий экран;
  - **Статистика прослушиваний** (топ треков и общее время), **Плавные переходы (Crossfade)**, **Встряхивание для переключения трека**, **Переименование и инфо о файле + Поделиться**.

## Основные возможности

- **Медиатека (только ссылки URI)**:
  - при первом запуске список пуст — плеер не сканирует сам весь телефон и не копирует файлы;
  - **«Добавить файлы»**, **«Папка / SD»** (проводник по конкретной папке без сканирования всей карты памяти) и **«Импорт папок»**;
  - форматы: MP3, FLAC, OGG/Opus, WAV, AAC (raw `.aac`), AMR, MKA, WMA и др. (**`m4a` / `mp4` исключены**);
  - создание и редактирование своих **плейлистов**, избранное, поиск, сортировка, очередь, «Играть следующим».
- **Звук и вывод**: переключатель вывода (**Авто / Наушники / Динамик**, в т.ч. режим обхода как при звонке), качество **Hi-Res 32-bit Float**, **16-bit PCM** (оптимально для Bluetooth) и **Direct**, 10-полосный эквалайзер, Bass Boost и Volume/Gain.
- **Онлайн-радио**: ~80 станций России, США, Германии, Франции и Южной Кореи с выбором битрейта и автопереключением при сбое.
- **Оформление**: стили **Flat**, **Glass**, **Neon**, **Retro** и т.д., готовые и пользовательские темы, адаптивный акцент из обложки, AMOLED-чёрный фон.

## Сборка APK

### Через GitHub Actions (без локального Android SDK)
1. При каждом `push` в `main` workflow `.github/workflows/build.yml` собирает **`PoliSANPlayer-V1.6.apk`** (прямой APK в разделе **Releases → latest** и в **Artifacts → PoliSANPlayer-apk**).

### Локально (Android Studio / Gradle)
```bash
gradle assembleDebug
```
Готовый APK: `app/build/outputs/apk/debug/PoliSANPlayer-V1.6-debug.apk`.
> Файл `local.properties` с путём к SDK в репозиторий не добавляется (в `.gitignore`).

## Технологии

Kotlin · Jetpack Compose · Material 3 · AndroidX Media3 (ExoPlayer + MediaSession) · 32-bit Float DSP AudioProcessor
